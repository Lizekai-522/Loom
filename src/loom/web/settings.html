就绪度总览

绿色=已就绪；黄色=部分配置；红色=未配置。点卡片标题跳到对应设置。

模型与密钥

选择已验证的服务商与模型，填入 API key。保存后路由与密钥在执行器下一次调用时生效；首次保存需要重启一次执行器。

联网搜索

助手的只读调研来源。密钥只写入私有文件，页面上不回显。

域名邮箱

收信自动摘要；发信必须由你批准草稿。密码只写入私有文件。

独立双模型复核

DeepSeek Flash + 阿里云千问两个独立复核模型；生成签名密钥到私有目录。已配置过则需换新目录重新生成。

沙箱镜像

Python 候选在冻结沙箱里执行：无网络、只读根、非 root。登记 docker image inspect 输出的不可变 ID。

宿主用例（冻结终验）

粘贴 {"tests": [...]} 用例文件内容；系统计算冻结摘要并登记。批准计划中的摘要一致时才会被使用。

持久配额

滑动窗口内的模型/工具调用上限；配额台账只追加、不可改写。

成员与访问

本机身份管理。令牌只写入私有邀请文件（600），页面永不回显；新增成员后 API 与执行器需重启。控制台要求唯一具名用户，因此这里不能添加 user 角色。
