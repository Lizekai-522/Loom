# Loom 0.17.8 问题审查与实施记录

2026-10-28，先测 0.17.7：恢复、权限和计划专项 70 项主测试、21 项子检查通过。本机与受邀公网入口可访问。

发现并复现：租约过期时，如果预留未结算但没有处于未知状态的 effect，旧逻辑可能将任务自动重新领取；调用结果已保存、费用尚未结算时，人工待办也可能漏掉。独立临时库复现两个重领反例和一个待办遗漏；没有向真实模型发送请求。

处理：租约过期且任务仍有预留时进入 indeterminate，不自动重试或释放预算；失去有效执行者的预留及非终态运行中的异常任务进入租户隔离的人工待办。支持对结果已保存、模型调用及对应预留均匹配、执行者已失效的调用，由具名操作员凭外部证据登记实际用量；事务保留原结果、留审计，核对不构成验收或自动恢复。完成后原尝试次数与预算仍生效。没有匹配模型合同的预留继续冻结，需人工追查，不伪造退费或自动结算。

浏览器测试发现调用的 `done` 状态原被误显示为“已验证”；现改为“调用已完成”，不把调用结果当作独立验收。真实 JetStream 新样例初版错误预期已达最大次数的任务仍可恢复，按批准计划修正测试并保留失败证据；仍有剩余次数的路径由本地专项覆盖。

本机主库和公网库只读查询均未发现当前滞留预留或预留未结算时任务轮次已增加的记录；不推断未被保留的历史数据。数据库未因检查而改写。

本轮属于原 FR-024、FR-056、FR-058 的局部建设，生产身份、完整人工裁决、独立模型和多主机恢复仍未完成。公网体验不开放人工账务核对写操作，本机回环工作台提供该操作。
