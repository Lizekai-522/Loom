- 初版开发浏览器脚本等待任务进度 2/3，错误地将 submitted 算作独立 done，最终超时。实际两响应和 Docker 已成功，未重复付费调用；改为只读复核 0/3、候选 submitted 和 validator pending。未完成脚本的局部断言不算通过数。
- 只读本机核对初稿将 40 条 runs 当作 40 个 managed Goals；基线实际为 40 runs /29 managed Goals。改为逐表比较升级前备份与现库全部旧行，本机 HTTP 61 项通过。
- 只读执行证据脚本最初访问不存在的 review-input.ready 字段；改为校验 schema、subject 源码摘要及冻结终验来源，18 项账本对账通过，不新增模型调用。

原始失败 XML 留在源码工作区 artifacts，原始浏览器输出/尝试门闩留在公开目录之外 work；不分发会话文件或模型密钥。最终通过的 Chromium 45 项，不加入失败或重复验证数。
