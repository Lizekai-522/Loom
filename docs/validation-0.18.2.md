# Loom 0.18.2 验证记录

2026-10-29。前版 0.18.1 已通过回归、真实浏览器交互和公开仓库核对。本版只增加本机只读检查工具，不修改服务执行、预算或身份逻辑。

新增检查与公网访问专项共 35 项通过，覆盖执行器进程缺失、本机正常但 HTTPS 不通、拒绝非 Quick Tunnel 域名及不输出测试私有值。实际首次检查在 HTTPS 项失败，而本机、进程和 Docker 正常；随后再检查全部通过，公网会话及权限 12 项复测通过。无法确认首次失败根因，不把复测通过当成稳定可用保证。

检查不登录、不提交模型、不修改体验数据库。它确认进程存在、Docker 服务可查询和登录页可访问，不验证模型提供方、容器执行、冻结用例或独立验收。临时隧道可能失效、重建可能改变地址；正式体验前应从手机移动网络复测。

版本标识更新后，相关测试再次通过 35 项；队列空闲并备份两库后加载 0.18.2，实际只读检查全部通过，受邀入口版本、会话和权限等 12 项检查通过，未增加模型请求。

2026-10-29 补充：用户反馈“移动网络访问成功”，确认手机关闭 Wi-Fi 后可通过移动网络访问受邀工作台。此项为用户现场反馈，关闭当前地址的独立网络访问待办，不扩展为手机端完整业务执行验收。收到反馈后，本机只读检查七项再次全部通过。详见 `launch-readiness-2026-10-29.md`。
