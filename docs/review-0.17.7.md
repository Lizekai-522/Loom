# Loom 0.17.7 问题审查与实施记录

2026-10-28。基线计划、恢复和权限专项 68 项主测试及18项子检查通过。本机和受邀公网入口可访问。

发现：对部分完成的调用或已保存调用结果，旧版允许人工选择“确定未发送”。在隔离数据库中，三个反例均复现旧逻辑接受矛盾结论；最初测试曾因不同样例复用幂等键产生额外干扰，修正样例后重新确认三个反例，原始失败记录保存在工作目录。

处理：核对事务发现 `partial` 状态或已有结果时拒绝“未发送”；不释放预留、不变更调用、不追加核对事件。中文页面只使用布尔标志显示冲突并禁用对应选项，不暴露调用结果；后端在提交时独立复核。没有此类证据时仍需操作者具备可靠依据，预检本身不证明调用未发送。已核实用量的完成核对路径仍保留原部分结果及明确的人工记账。

两份现有数据库的只读检查未发现当前“未发送但有结果”记录，亦未在可识别审计事件中发现“曾记为部分后又判未发送”；数据缺失时无法排除所有历史冲突。历史记录未修改。

该项仅是恢复与人工核对的局部改进，完整人工裁决、独立双模型、生产数据库和多主机恢复仍待建设。
