# Loom 0.17.7 验证记录

2026-10-28。起始 0.17.6 的恢复、权限、计划专项为 68 项主测试和 18 项子检查通过；本机和受邀公网可访问。

隔离数据库先复现三个旧版反例：部分状态无结果、部分状态有结果、未知状态有结果时，均可错误登记为未发送。首版测试复用了幂等键导致部分干扰，已修正并保留两次失败证据。修复后，对应事务拒绝冲突，预算、证据、运行状态、事件与收据保持不变；原本没有部分证据、确有外部依据的未发送核对仍可使用，完成核对保留原始结果。

完整本地套件 980 项主测试和 385 项子检查通过，无失败或跳过。该套件执行时版本标识为 0.17.6，随后仅更新版本标识与说明并进行针对性复测。涉及操作、模型网关、执行、页面和公网权限的专项 166 项主测试、92 项子检查通过。真实 Docker 和 JetStream 专项 11 项通过，模型请求使用替身；新增 JetStream 用例核对矛盾决策不产生日志、有效人工核对产生一次事件。未新增付费模型请求。

隔离数据库中的 Chromium 测试确认：有部分证据时中文界面禁用“确定未发送”且不显示结果内容；没有此类证据时该选项可选择，实际提交仍需要用户核实依据。后端始终重新验证并限制跨租户访问。

更新版本标识后的恢复、API 和访问控制专项 115 项主测试、21 项子检查通过。队列空闲后备份两库并加载 0.17.7；本机 64 项、公网及源码导出 27 项检查通过，两库与本次升级前备份一致。新增证据标志的本机、公网、匿名拒绝与只读检查 13 项通过，没有新增事件、收据或执行请求。
