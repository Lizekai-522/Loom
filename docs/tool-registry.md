# 本机工具注册表

0.18.5 将已经实际使用的 Python 隔离测试接入代码内固定注册表，工具标识为 `tests.run`，版本为 `loom.python-tests/v1`。普通开发、修复和有界 Rebind 的公开检查与隐藏终验均经此适配器调用。工具登记不授予执行权，实际调用仍需精确批准合同、有效 claim、开发或修复角色，以及 `workspace.write` 和 `tests.run` 两项能力；原暂停、预算、输入绑定和独立验证要求继续执行。

工作台的“推进指引”中打开开发或修复节点的“工作台执行”，可读取中文工具能力提示。`GET /v1/tools` 对有读取权限的租户返回版本、支持角色、作用域和静态输入合同；受邀公网可以读取，不能注册、修改或执行工具。读取失败不阻塞原有排队或取消流程，也不会显示为已通过健康检查。

实际参数是内存中的相对 Python 源码与 1–32 个宿主冻结 JSON 用例，由原 DockerSandbox 完成路径、体积、输入和输出校验。代码只进入固定镜像的非 root、无网、无宿主目录容器。普通执行的评估事件记工具标识与版本；修复流程沿用原有候选、公开检查和终验事件，不向模型返回隐藏用例。

本项只推进 FR-039 注册中心的固定内置适配器；运行环境是否配置与是否健康分开。尚不提供动态插件安装、任意 shell、HTTP 出口、MCP、模型 Function Calling、跨工具限流或通用工具健康监控，相关原需求保持未完成。通过宿主用例的候选仍等待独立模型复核。
