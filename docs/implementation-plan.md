## 本轮环境限制与处理

| 已知条件 | 当前处理 | 后续进入条件 |
|---|---|---|
| 仅 Flash 已接入真实请求 | 使用项目私有文件注入密钥，不写全局环境，不进入候选容器；官方 JSON mode 加严格 source 协议，任务预算/lease/未知态受控 | 接入符合独立性策略的第二模型与受信结果认证，完成独立验证后才允许验收；同一 Flash 的七个角色不构成双模型 |
| Docker Linux daemon 已可用 | 固定摘要 runner 镜像；每例独立容器，非 root/只读根/无网络/无宿主挂载，CPU/内存/PID/时间/输出限额和 host 黄金比较已实测 | 扩展到任意仓库/依赖前单独设计权限和工具边界；生产多租户需更强隔离、供应链与出口鉴权 |
| 本轮为单主机 SQLite | `BEGIN IMMEDIATE` 串行事务作为一致性参考；数据库保存容量设置避免同库实例配置漂移 | PostgreSQL 原子预占、claim 争用、多副本接管和分区故障测试通过 |
| HTTP API 已有本机具名角色 | operator/worker/viewer 及 subject 绑定，旧 developer 仅兼容 fixture、无 control；控制动作审计留痕，无自报验证完成入口 | 生产 OIDC/人员认证、移除兼容面、独立验证身份、双人高风险审批与部署权限实测 |
