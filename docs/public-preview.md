# Loom 临时公网体验

交付检查点：2026-10-29，版本 0.18.3。用户要求 10 月 29 日 18:00 左右可公网在线体验，当前采用本机运行与临时 HTTPS 隧道。此入口与本机开发工作台分开，使用独立数据库、租户、操作员、执行器及访问码，不公开既有开发记录。

工作台执行准备区域新增[执行器心跳](executor-status.md)：超过 15 秒未收到心跳时提示检查主机。心跳不代表模型或容器健康，实际发起仍受原授权、预算和独立验证约束。

## 访问与首轮测试

1. 在本机打开 `work/loom-public-preview/访问信息.txt`，读取当前地址和体验访问码。只向受邀测试者分享这两项；不要分享模型配置或内部身份文件。公网访问码与模型 API 密钥不同。
2. 打开地址，输入访问码，进入中文工作台。受邀人员共用测试空间，请使用测试内容。
3. 点击“新建词频体验”，生成新的目标草案与可执行计划。该操作不会调用模型。也可以选择仍未执行的初始词频体验。
4. 打开“计划”，核对需求、三项任务、预算和终验摘要，勾选审阅框，点击“批准当前计划”。批准才会创建任务。
5. 打开“推进指引”，在需求分析任务点击“准备本机执行”。填写理由、核对预算并勾选授权框，点击“提交给本机执行器”。等待候选提交，再刷新任务与证据。
6. 打开“产物 / 输入预览”，读取需求候选正文，选择“实现并隔离测试词频程序”为目标，勾选核对并批准精确辅助输入。批准输入只允许读取，不代表需求已经独立验证。
7. 回到“推进指引”，在开发任务准备并显式提交执行。真实 Flash 生成程序，真实 Docker 在无网络、只读根、非 root 与资源限制下执行；宿主冻结终验判断结果，隐藏用例不发送给模型。
8. 在“任务”中点击“查看源码与导出”，可核对并下载原始main.py和版本记录JSON；下载会再次核对精确版本，不新增模型费用。[源码说明](source-exports.md)。
9. 在“任务”和“人工待办”核对执行、用例与费用，在“事件”核对审计链。通过后仍显示“待独立复核”；独立第二模型按用户决定待配置，不能宣称 Goal 最终成功。

排队请求可以取消；执行已开始后，受邀用户可在共享体验空间使用运行暂停/终止。暂停不会保证撤销已发出的外部调用；未知结果和预留继续保留。回执丢失时先“重新读取执行条件”，同页面重提会沿用原幂等键。刷新整个页面会丢失该键，必须先查看记录，不能盲目重复。worker 重启只核对已有执行账本，不自动重发已开始的模型调用。

任意新目标、工作流 JSON、审阅和审计功能仍可使用。词频模板用于快速测试；其他 Python 任务须由本机维护者配置独立宿主终验，并按原流程审阅批准，不允许公网上传并自封隐藏验收标准。

## 启动、关闭与恢复

在源码目录执行，路径按当前工作区布局：

```powershell
.\scripts\start_local_docker.ps1 -RuntimeRoot '..\..\work\loom-docker-cache'
.\scripts\start_public_preview.ps1
```

需要已安装的 `work/loom-venv/Scripts/python.exe`、私有 Flash 配置、不可变 Docker 镜像记录与 `work/loom-tunnel/cloudflared.exe`。首次环境安装见 README；启动器不复制/打印模型密钥，不在命令行传密钥。维护者可用 `-WithoutWorker` 仅验证排队、取消和页面，不调用模型。

```powershell
.\scripts\stop_public_preview.ps1
.\scripts\start_public_preview.ps1
```

关闭脚本检查已登记 PID 和命令，保留数据库、日志、密钥和失败证据。停止过程中若有在途请求，重启后先核对调用/预留；不要重新运行旧付费探针。`work/loom-public-preview` 内的 `api-error.log`、`worker-error.log`、`tunnel-error.log` 与进程记录用于本机排障，不作为公网下载目录。

本机入口继续使用 `scripts/start_local_dev.ps1` 和 `http://127.0.0.1:8796/console`，无需输入凭据。**不要把这个自动操作员端口直接接到公网隧道。** 公网专用端口默认为 8799，仅绑定回环，由独立受邀会话边界保护。

本机须保持开机、联网，Docker、API、worker 和隧道须持续运行。没有更改系统休眠策略。正式演示前确认电源设置，并从手机移动网络重新验收，覆盖不同网络访问。

2026-10-29 用户已反馈手机移动网络访问成功，当前入口的独立网络访问已确认；后续地址变化或正式体验前仍应复查。该结果不等于手机端完整模型执行或独立验收通过。[上线记录](launch-readiness-2026-10-29.md)

上线前可在源码目录运行以下只读检查；结果不打印访问码或模型密钥，也不调用模型。它核对登记的进程、Docker 服务、本机及临时 HTTPS 登录页；进程存在和页面可访问并不证明模型、容器执行或独立验收通过。

```powershell
..\..\work\loom-venv\Scripts\python.exe -X utf8 .\scripts\check_public_preview.py
```

## 会话和预算

访问码只保存在本机私有目录。登录使用 Secure / HttpOnly / SameSite=Strict 的主机 Cookie，不向页面下发 API Bearer 或模型密钥；会话最多 4 小时，重启服务或修改访问策略后失效。所有写入检查精确 HTTPS Origin，限制登录/写入速率、请求体和活动会话数。公网禁用 worker 提交/认领、账单裁决、旧通用增任务、Swagger 与私有路径。

体验空间最多 20 个目标，每个目标预算不超过 $1 与 3,200,000 词元，包含已终止目标，不会因重启清零。预算按现有 Flash 上下文上限保守预留，不表示实际消费；实际已知用量结算，未知结果保留预留。三项模板任务各 $0.32 / 1,060,000 词元，合计在目标上限内。公开空间全部目标的配置金额上限为 $20，任何模型调用仍须逐项显式确认。供应商价格/账单未独立核验。

这是单机受邀体验，不是生产 OIDC、多租户人员隔离或完整 62 项验收。使用 [Cloudflare 官方 Quick Tunnel](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)，无需服务器或自有域名；地址重建会变化、没有可用性保证，不支持 SSE。本项目使用普通 HTTP 轮询。地址和访问码始终以本机私有访问信息文件为准。cloudflared 来自 [官方 Windows 下载](https://developers.cloudflare.com/tunnel/downloads/)，本轮版本 2026.10.3，SHA256 `76b2805253d0d6ffacb092a7acfbee99e7af6917835c0c5410e23f3ef5052da2`，不打入项目源码包。
