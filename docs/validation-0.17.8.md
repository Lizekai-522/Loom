# Loom 0.17.8 验证记录

2026-10-28。0.17.7 基线恢复、权限及批准计划专项 70 项主测试、21 项子检查通过；本机和受邀公网入口可访问。

隔离数据库先复现两项租约过期后的自动重领反例和一项人工待办遗漏。修复后，无论预留缺少对应调用还是调用结果已保存，过期任务都不会自动重新领取，预留保持冻结；已有执行者的健康预留不误报。还验证了迟到的合法结算不会让异常任务从待办消失、事件回放与任务状态一致、预算超限及尝试次数仍生效。

本机具名操作员可核对已保存结果的完成调用和匹配预留：权限、租户、有效租约、证据、幂等与账目均在事务中检查；保留原调用结果，核对不会自动恢复或产生独立验收。未匹配受支持模型调用的预留仍冻结，需人工追查。公网预览不开放该账务写操作。

完整本地回归 985 项主测试、387 项子检查通过，失败及跳过为零；该套件运行时版本标识为 0.17.7，随后更新版本标识、文档，并修正浏览器发现的调用状态文案，再作针对性复测。真实 Docker 和 JetStream 专项 12 项通过，模型 HTTP 使用替身，本轮无新增付费调用。首次真实基础设施新增样例误认为单次尝试合同允许继续恢复，已按合同修正并保留失败记录。

隔离 Chromium 实测中文待办、用量核对和账目变更：预留由 100 降至 0、人工记账 10 微美元与 20 词元、调用结果保留，运行和任务仍待人工处理。随后修正页面将调用完成误称“已验证”的显示，复测显示“调用已完成”。现存主库和公网库只读核查均未发现滞留预留或未结算预留对应的后续任务轮次；无法据此判断未保留的历史状态。

更新版本标识后的针对性复测 146 项主测试、23 项子检查通过；随后单独新增的完成调用超预算反例通过，不包含在完整套件或该专项数量内。队列空闲时备份两库并加载新版本；升级后本机 64 项、公网与导出 27 项检查通过，两库与升级前备份一致。新待办及核对状态的本机、公网、匿名和公网写入限制检查 13 项通过，没有新增事件、收据或执行请求。

该项仍属于 FR-024、FR-056、FR-058 的局部建设。完整人工裁决、生产身份、独立双模型、生产 PostgreSQL 和多主机恢复未验收。
