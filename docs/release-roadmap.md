## 当前能力与明确缺口

0.20.0完整词频体验已跑通真实新目标：Flash生成、实际Docker6/6、Flash/Pro各一次独立复核、2份真实Ed25519签名、Gate-V、Goal验收、源码与证据下载。中文页面明确区分生成Goal额度与额外复核项目池，未知结果保持占额且不自动重发。原七角色模板、多角色体验和历史冻结计划保留。

本机临时公网可用；生产人员身份/职责隔离、稳定托管、独立外部checkpoint、全部七角色语义验收与完整裁决、通用工具/出口/分布式配额、PostgreSQL完整运行Store、多主机及知识经验等仍待逐项实现。复核当前使用私有账本与总项目池，不等于全局分布式配额已经完成。SQLite新副本冷开通过不等于生产回滚或投影重建。

接下来按[上线后计划](next-steps-2026-10-30.md)追踪，保持每轮先测、修复、再推进与同步仓库。原62项完整功能目标保留，R01/FR-051/052完成了本机程序签名闭环部分，FR-047/043等仍partial。没有把模型候选来源记录当成内容验证，也没有用新入口自动验收历史多角色任务。
