# Loom 0.18.3 问题审查与实施记录

发布资料生成曾因隔离 API 夹具未提供身份而被现有认证规则拒绝；为夹具添加无网络用途的测试身份后重新生成，不修改正式鉴权规则。

版本更新后复测 97 项通过；队列空闲备份并加载新版，本机与公网心跳及数据检查 18 项通过，两库全部业务数据表与升级前备份一致。

2026-10-29。现有执行预览可以说明配置已登记，但不能说明后台执行器近期是否活动；0.18.1 的等待提示只能说明页面观察到排队，缺少进程侧信息。

本版新增独立进程观察和经过租户鉴权的只读接口，在中文工作台显示近期、过期、未观察、未配置和未知状态。观察写入数据库外的运行目录，避免影响既有业务状态和已审阅的执行摘要；状态读取与原预览独立，读取失败不阻塞排队和取消。该信号不授予执行权、不触发重发，也不替代模型或容器检查。

实现审查时调整前端为独立读取，防止心跳请求缓慢时延迟取消操作。真实浏览器验证近期、过期及网络失败提示，并确认读取失败时仍能排队和取消。取消验证途中浏览器会话中断，重新打开后依据持久请求记录完成取消，不把中断当作通过。故障注入产生的网络错误为预期测试现象。

基线相关回归 76 项；新增专项 70 项；完整本地 1005 项主测试与 387 项子检查；真实 Docker/JetStream 专项 12 项通过。本轮没有新增真实模型调用，基础设施专项使用模拟模型响应。FR-048 仍为部分实现，独立第二模型及生产门槛继续保留。后续结果见 `validation-0.18.3.md`。
