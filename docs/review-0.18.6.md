# Loom 0.18.6 问题审查与实施报告

第一轮 0.18.5 完成测试、加载与公开仓库逐文件核对后，第二轮按 S3 继续上下文预算。原有辅助上下文和网关总请求体已有静态上限，但任务无法单独冻结更紧上限；现增加可选批准字段，并对实际序列化 JSON 请求体做精确 UTF-8 字节检查。

检查覆盖普通 Python、结构化角色和每次有界修复发起；在新增预算/effect 之前拒绝，超限不触发自动修复。字段省略或 null 时旧摘要不变，已批准合同不允许提高上限。中文计划说明和执行预算展示同步更新。

原有 token/费用预留继续沿用保守合同；不得用字节数减少词元预留、伪造精确 token 测量或声称完成上下文优化及三层配额。真实第二模型仍待配置。

本轮初步专项 100 项主测试和 19 项子检查通过，补充修复反馈增长以及真实 Docker 正反例后，继续运行最终专项与完整门槛。最终数量与实际入口记录见同版验证和外部发布报告。

审查另发现 API 说明首页仍标历史 0.8.0，已同步当前版本，并补充心跳、工具目录和任务上下文上限；生成的 OpenAPI 仍以实际应用为准，未开放的其余设计接口继续保留边界。

本轮测试未发现新增产品失败。报告汇总命令曾误用源码目录作为工作根而未读到私有浏览器日志，未生成或覆盖报告；改为以脚本绝对位置定位的独立汇总器后通过。最终专项 128 主/28 子、完整 1044 主/387 子、真实基础设施 18 项与浏览器 8 项通过。
