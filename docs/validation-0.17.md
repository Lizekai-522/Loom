## 拒绝与故障证据

来源漂移在存计划/批准/模型准入/返回/提交/意见消费处拒绝，旧意见可历史回读并标stale。隐藏输入、答案、名称及执行stdout不进入审查/修复prompt。未知调用保留预留，暂停/终止/失租不保存迟到候选，已知响应按usage结算。错误subject/行号/额外权限/重复或围栏JSON、无问题却批准fixer、篡改宿主判据/增加次数/自动repair、legacy批准、预算不足及硬依赖绕过均拒绝；并发只有一个领取，审计失败回滚epoch和新grant。

首次新测试发现：不同subject反例共享dict引用而同时修改两端，已改为独立拷贝；更重要的是单次fixer失败沿用旧路径回pending，已在同事务保存失败报告并转人工。修复后的首轮断言又误将非open时claim的Conflict写成None，已按正确拒绝语义修正。全部原失败XML保留，32专项与898/396最终通过，零skip。浏览器fixture首次因work脚本缺仓库导入路径启动失败，补入口后通过，未访问私密配置。
