# 工具结果未知时的人工核对

0.18.9 对已登记 `tests.run` 提供专用核对。先停止相关进程，核对调用、轮次、请求摘要及容器日志。在本机工作台“人工待办 → 工具结果人工核对”填写结论、依据引用与说明并确认；也可运行 `python scripts/reconcile_tool.py --help` 查看本机CLI参数。身份和日志保存在源码外，依据不要包含密钥。

结论“确定已执行”只把未知效果记为已核对，不证明用例通过；“确定未执行”需要可靠依据，已有部分/结果证据时禁止。拥有者租约仍有效、调用/轮次/请求摘要不符、其他租户/运行或非登记工具均拒绝。模型调用只能走原有账务核对，工具接口不接收费用字段。公网用户可查看状态，核对写入只在本机进行。

核对命令、效果状态与审计/outbox同事务；同一key和相同参数可读取原回执，更换参数或第二个结论拒绝。原始结果保留，历史准入次数不清空，只释放已确认的在途名额。原任务和执行请求不自动恢复、不补造测试证据、不签名或判为成功；取消/暂停保持原状态。需要再执行时须单独审阅原合同和尝试上限；同一稳定工具操作不会自动重放，必要时创建明确的新计划/新目标。

这是单机具名适配器的人工声明，不等于生产双人审批或独立信任根。通用外部工具、自动提供方核账及完整灾备恢复仍在计划中。
