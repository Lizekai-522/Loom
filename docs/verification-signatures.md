# 验证签名合同

0.19.0提供本机受信适配器使用的Ed25519签名与双验签核心；没有网络/数据库写、任务完成或HTTP私钥登记接口。`GET /v1/verification-capabilities`只读描述能力，当前configured和completion_connected均false。模型正文自报authenticated不会成为认证结果。

每份签名覆盖租户、run/task/epoch、已批准计划、精确产物、规则集、冻结测试摘要、执行/提交事件及输入摘要，以及网关模型/调用/请求/响应/意见摘要。受信公钥白名单绑定verifier和实际模型，并核对密钥生效窗口、吊销及最长1小时有效期。两个verifier、实际模型、公钥材料和调用均须不同；多个别名或同一公钥换名称不能构成独立性。

只有验签通过才由适配器构造authenticated=True。真实的拒绝结论保留passed=False，Gate-V拒绝。验签证明对应私钥签过这些字段，不独立证明宿主测试真实或生产人员分离；可信宿主证据、账本模型来源与最终提交仍须在消费时重新核对。私钥不得进入API、模型、容器或源码，下一轮连接受信结果和持久账本。
