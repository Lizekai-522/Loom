# Loom 公网体验步骤

这是本机运行的受邀临时HTTPS体验。地址与访问码在维护者本机私有文件中，访问码不进入公开仓库。需保持本机开机联网、Docker及入口/生成执行器/独立复核器/隧道运行。

1. 输入体验访问码，进入中文工作台，点击“完整词频体验”。创建只生成草案，不调用模型。
2. 打开“计划”，审阅需求、冻结测试摘要与预算，勾选后批准当前计划。
3. 打开“推进指引”，选择“准备本机执行”，读取条件，填写理由并明确确认后提交。Flash生成程序，实际Docker执行冻结宿主用例；等待候选提交。
4. 点击工作台“刷新”，在“任务”查看6项用例结果，并查看/下载main.py。测试失败的候选不能申请最终通过。
5. 打开“独立复核”，核对当前程序版本、Flash/Pro、独立项目总额度及本次最多$1.85预留，填写理由、明确勾选后申请。原生成目标额度上限$1，独立复核另计，已知用量释放未用额度。
6. 等待两模型复核；签名通过后可下载证据，点击“刷新工作台状态”。本路径只有一个程序任务，签名通过且冻结判据全部满足后，目标显示验收成功。模型发现问题、来源变化、暂停、未知调用或预算不足会停在可核对状态，不能自动重发或改为成功。

“新建词频体验”保留原多角色流程。角色候选的模型来源不等于内容独立验证，原有未完成角色不会因为新入口而自动验收。自定义目标仍须配套工作流及本机注册的独立宿主验收，不应把词频用例套给任意需求。

会话在服务重启后需重新输入访问码；历史Goal、审计、预算及复核请求保存在私有数据库。started后失联的复核保持占额，重启不自动重发。维护者先核对台账，再按恢复说明处理。临时隧道可能变化，稳定域名/服务器和生产身份尚未交付。
