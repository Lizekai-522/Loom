# Loom 0.18.10 问题审查与实施报告

用户已指定Pro，但旧网关、只读角色合同、来源schema及界面只认Flash，准入预览也只按Flash价格。新增官方Pro白名单、仅reviewer的规范路由与模型价格核对、严格结果/来源schema和中文模型来源展示；旧Flash路径和冻结计划保持兼容。

专项首测六项fixture初始化失败：测试数据中reviewer/fixer引用同一limits字典，调高reviewer费用也调高fixer导致Goal预算拒绝。已将reviewer limits复制为独立字典，保留原失败并复测通过。新增真实基础设施测试覆盖Pro意见到明确批准Flash修复，再由实际Docker核对冻结终验；模型HTTP为替身。原62项与正式双签门槛保持未完成项，不以候选正确schema替代真实性验收。

真实Pro来源浏览器首测的文本选择器同时命中任务与隐藏人工待办，触发严格模式拒绝。已限定为任务列表后复测；没有因此重复发起模型。原失败日志保留，页面模型来源本身已正确显示。

随后浏览器脚本假定滑动窗口内次数始终为1，但检查时已过窗口，返回0是正确行为。改为核对Pro独立资源在途为0、当前窗口次数合法且审计中恰有一次历史准入，避免把时间窗口当成永久总次数；不重置配额或重发模型请求。

实际加载后公网检查失败，先出现域名解析异常，随后旧隧道日志明确返回 Unauthorized: Tunnel not found；进程仍存在不代表隧道有效。按已有授权备份访问配置，仅替换核实过身份的隧道进程，保留访问码与业务数据，更新地址后重新核对会话、权限和旧数据。旧地址的手机成功记录不能当作新地址的独立网络验收。

维护脚本复制时重复添加UTF-8 BOM，导致首行错误但隧道修复其余动作完成；已修正编码，并只读核对私有备份、访问码一致和新登记进程，没有为重跑脚本再次换地址。新公网浏览器初次用open重建了浏览器上下文，丢失已加载会话；改为原上下文导航后复查，不将加载会话当作手动表单登录测试。

发布检查按既有规则拒绝artifacts目录。将已脱敏的真实Pro用量/状态摘要移至docs供审阅，原始测试日志继续保存在发布目录外；没有放宽凭据、数据库或原始输出的发布排除规则。
