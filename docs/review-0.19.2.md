# Loom 0.19.2 审查与修复报告

第二轮已测试发布后，新增中文独立复核操作、额外额度明确确认、历史签名证据及常驻执行器。请求只接受当前预览摘要和理由，不接受客户端签名、认证字段或额度修改。旧配置兼容，生成预算与旧计划冻结摘要保持不变。

审查发现前置失败会使复核watch退出并留下queued任务。现将尚未启动的来源变化、暂停、额度不足持久阻断，零调用、零费用；不能接管已经started的请求。新PowerShell脚本最初缺少Windows PowerShell 5.1所需UTF-8 BOM，静态解析失败，已补编码并重新解析，未用失败脚本启动服务。

回归首次收集包含未启用的可选集成环境，保留原始收集报告；本轮将完整单元集合与显式开启Docker/NATS的基础设施门槛分别统计，不把未执行的PostgreSQL等可选项写作通过。
