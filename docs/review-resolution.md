4. 对修订示例运行原审查中的五组最小反例：

| 反例 | v2.1 示例结果 |
|---|---|
| 强制双签 pending/disputed/blocked/single/signed | 前四种拒绝，仅 signed 且至少两份有效独立签名时通过；另测单签零验证记录拒绝、一个有效记录可通过 |
| 业务已占验证保留边界或总容量已满 | 业务拒绝；保留边界下验证可用；总容量满时全部拒绝 |
| 改事件类型与操作者 | 完整事件信封摘要变化 |
| 空 submission_key | 规范编码 null，摘要正常产生 |
| 验收未过但连续空闲 | 返回 stalled，不返回成功 |
