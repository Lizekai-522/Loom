# Loom 0.18.9 问题审查与实施报告

0.18.8 已持久保留未知工具占额，但只支持模型账务核对，缺少工具专用处理入口。新增具名操作员服务、严格API、中文工作台和CLI，精确绑定调用/轮次/请求摘要，核对配额来源及实际工具身份后只改变未知效果状态。

所有费用、用量、任务输出和测试证据保持原值；保留部分结果，不允许将部分证据改判为未执行。活动租约、错租户/运行、旧绑定、相冲突命令及审计写失败均拒绝或回滚。公网写路径继续禁止，模型账务入口与工具核对分别验证。没有新付费请求或独立签名，FR-024/047/056/058仍partial。

浏览器截图复核发现已核对状态显示英文reconciled，且旧通用effect事件被标作模型事件；已补中文状态并将通用事件称为调用，避免混淆工具和模型。追加界面复查并重建wheel，原八项功能检查保留。
