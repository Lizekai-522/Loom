# 执行器心跳与中文状态

0.18.3 在“推进指引 → 准备本机执行”中显示后台执行器最近的心跳。使用当前 `scripts/run_local_executor.py` 启动的执行器每两秒写入一次本机进程观察；模型等待与容器执行期间继续更新。页面读取执行条件时单独读取心跳；正在排队或执行时随既有轮询刷新。

最近 15 秒内的心跳显示近期活动；超过窗口提示检查执行器；首次运行、未配置、损坏或不可读分别显示未观察、未配置或无法确认。执行器停止后最多仍有 15 秒的近期活动记录，不把它解释为当前一定在线。页面未持续轮询时，显示的是最近一次读取结果。

`GET /v1/executor-status` 要求现有租户读取权限；受邀公网必须先登录，不开放状态写入路由。返回状态、观察年龄和时间窗口，不返回工作目录、模型配置、内部身份令牌或异常正文。每个数据库、租户、唯一 Worker 和执行器配置 ID 使用不同观察键；身份不唯一时不推断正常。

观察文件位于数据库旁的独立运行目录，文件名为作用域摘要，正文只含版本、摘要和时间；采用临时文件原子替换，不写业务数据库或事件链。记录可丢失或过期，不能作为持久审计证据，不构成跨操作系统账户的独立认证。

心跳不代表模型或 Docker 健康，不改变执行预览摘要、授权、预算、幂等、排队、取消或重试。心跳接口读取失败也不会阻塞执行条件读取和取消操作。所有实际发起仍由原后端规则核对，未知调用仍需账本核对。

此项为 FR-048 可观测性的局部建设。完整指标、追踪、告警、生产身份和多主机监控仍未验收。
