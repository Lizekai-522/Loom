# 独立复核请求、预算与结果消费

0.19.1先交付私有CLI和受信适配器，下一轮接中文操作。`scripts/configure_verification.py --help`由本机具名操作员配置源码外的加密Ed25519密钥、身份、模型入口和项目复核总额度；`scripts/run_verification.py --help`支持只读preview、明确enqueue、status及私有drain/watch。预览不加载私钥或模型秘密，不发请求。

生成任务继续使用原Goal额度。独立复核有单独、明确配置的项目预算池，原Goal金额不被暗改；该项费用不包含在公网生成Goal的$1额度内。每次复核最多预留1850000微美元，覆盖Flash/Pro各一份新冻结reviewer合同；典型项目池配置为2000000微美元总额，公网用户不能调高。已知用量在私有复核账本结算，源账本保留汇总和签名回执。未知调用继续占额，重启不重发，不能用清空状态、滑动窗口或换key重复申请同一源任务轮次。

请求冻结源租户/run/task/epoch、计划、程序/宿主用例及执行/提交事件，并将原始Goal需求、源任务instruction和验收判据纳入输入摘要。两个模型仅取得精确代码和宿主摘要，不取得隐藏用例、模型密钥、签名私钥或任意工具。每份签名由受信服务重建已知网关回执和schema合法候选后签发，模型自报身份/认证字段无效。

两份真实签名消费前重新核对当前来源、宿主通过、未结算调用、运行控制和预算；签名记录、Task完成与审计/outbox同事务。模型拒绝则保留候选并转人工；暂停或来源变化后不放行，结果未知保留额度。Goal验收仅支持注册的schema.valid/tests.pass/report.traceable，且全部任务都必须有当前签名完成记录；多角色未完成时仅验证当前任务，不伪造Goal成功。

签名密钥目前是同一本机账号下的私有加密材料，不能当成生产职责隔离或独立远端信任根。原62项、生产身份、完整恢复与通用工具继续追踪。官方分词器下载研究曾超时，本轮没有据未验证的词元估计降低原完整上下文预留。


0.19.2：工作台增加“独立复核”。选择已测试程序，核对独立复核总额度和本次预留，填写理由并明确勾选后申请。结果自动刷新；可下载包含签名、模型回执和公钥的JSON证据，读取与下载不会新增费用。程序通过不等于其他多角色任务完成。常驻复核器重启只处理从未started的排队请求；started后失联保留占额，人工核对。启动前不满足条件的queued请求持久阻断，零调用。

具名本机操作员可先运行configure_verification.py配置源码外私有材料与明确池额度，再在私有执行器配置添加verification_config指向其config.json。start_local_dev.ps1及start_public_preview.ps1会按配置启动私有复核进程；无配置时不启动。heartbeat仅表示近期进程观察，不能代替供应商或私钥健康检查。
